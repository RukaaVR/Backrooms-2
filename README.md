# THE BACKROOMS: BEYOND REALITY

A first-person Backrooms survival-horror game built on a **custom native C++20
engine** (SDL3 + OpenGL 4.5 + Jolt Physics + OpenAL Soft). No commercial or
open-source game engine is used; every level, material, mesh and sound is
generated by project code.

> Status: in active development — see `PROJECT_STATUS.md`.

## Building

Requirements: CMake ≥ 3.24, a C++20 compiler (GCC 13+, Clang 17+, MSVC 2022),
Ninja (recommended), Git. On Linux also: X11/Wayland dev headers, OpenGL and
OpenAL dev packages, e.g. on Ubuntu 24.04:

```bash
sudo apt install build-essential cmake ninja-build libx11-dev libxext-dev libxrandr-dev libxi-dev libxcursor-dev libxfixes-dev libxss-dev libxkbcommon-dev libwayland-dev libgl-dev libegl-dev libopenal-dev
```

Configure and build (dependencies are fetched automatically):

```bash
cmake -S . -B build -G Ninja -DCMAKE_BUILD_TYPE=Release
```

```bash
cmake --build build -j
```

Optional: pre-build shared dependencies once (faster multi-tree builds):

```bash
tools/scripts/bootstrap_deps.sh ~/.cache/backrooms-deps
```

```bash
cmake -S . -B build -G Ninja -DBR_DEPS_ROOT=$HOME/.cache/backrooms-deps
```

Run: `build/bin/BackroomsBeyondReality` (the `data/` folder next to the
executable is required). Tests: `ctest --test-dir build --output-on-failure`.
